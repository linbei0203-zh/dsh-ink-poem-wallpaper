# 水墨诗词壁纸 · Ink poem wallpaper

每天一句中国古典诗词，题在一幅随句意生成的水墨山水上，作为 Harness 的背景壁纸。

Every day a Chinese classical couplet is set into a generated ink-wash landscape that serves as the Harness wallpaper.

## 它做了什么

- **背景是一幅画，不是一张图。** 画面纯 SVG 现场生成，随诗句的意象变化：写月的句子长出月色与远山；写山的句子叠出远、中、近三重山影，并沿山脊带皴笔；写水的句子给出水面、涟漪、倒影和一只孤舟；写鸟的句子添几只两笔掠过的飞鸟；写雨雪的句子落墨点。每次还会从几种构图里挑一种（开阔湖面 / 一侧高峰留白 / 层叠雾障 / 低岸平水），所以连着几天看不会像同一张明信片换了颜色。同一句永远长出同一幅画。
- **诗句不在中间。** 插件会实测输入框的实际位置，算出对话区占用的横向范围，再把诗句放进旁边真正空着的那条边栏；右侧边栏展开时会自动改到左边。默认靠上、靠右，因为那里视线先到，也不会被常用输入框压住。
- **可以竖排，也可以横排。** 默认竖排（右起，传统题画的方式），因为它最省地方、最能塞进边栏。设置里可以改成横排——只有当边栏真的够宽时才生效，否则会自动回到竖排，避免压在对话上。
- **字体不是板正的印刷体，而且每个字都保证能画出来。** 四款：行楷（系统字体，默认）、草书（刘建毛草）、行草（志莽行书）、行书（龙藏）。后三款随插件一起安装，并且已经按本插件的全部诗句**逐字裁切**：每款字体都完整覆盖 1291 个用字，所以不会出现某个字缺字形、变成方块或串字的情况（之前魏碑乱字就是这个原因，已弃用）。字外带一圈纸色/夜色柔光，字压在山水上也读得清。

- **位置和字号可以自己定，定完就记住。** 直接把诗句拖到想放的地方即可，拖动后位置按窗口比例存下来；此后每天换句、刷新、重开，都还是那个位置、那个大小。设置里另有「小 / 标准 / 大 / 特大」四档字号，和「恢复自动」一键回到自动避让。
- **朱印是一枚固定的秦式鸟虫篆古印，不随诗句变化。** 印面是鸟虫篆（鳥蟲篆）风格：满版盘曲的鸟形与虫形笔画，外围一圈朱红边框，取自秦传国玺一路的印式。用的就是用户提供的那张原图：已去掉右下角生成水印、补回被裁掉的左边距、按印泥色重新上色。
  - **边框是刻出来的，不是画出来的。** 边框不是一根规规矩矩的矩形：外缘一圈起伏、内缘起伏更大（刻印时是顺着笔画掏的，所以内缘更毛），四角带崩裂，边上有细小的石花与飞白，整体压着朱砂颗粒感。做法是按石印的磨损规律重新生成了一圈边框，再把原印面套进去，所以放大了也经得起看。
  - **镂空**：只有边框和笔画带印泥，其余全部透出纸色。
  - **形状**：方印 / 圆印是两张各自生成的印面（圆印有自己的一圈圆边，不是把方印裁成圆的）。
  - **夜色**：夜里那套纸色下印面会自动提亮一档，免得朱砂发暗成褐色。
  - **大小**：设置里小/标准/大/特大四档，也可以**把鼠标放在印上滚滚轮**自由缩放。
  - **位置**：**直接拖动朱印**到任意位置，松手即记住，与诗句位置互不影响。设置面板里有「复位」。
  - 印面不依赖任何字体，因此在任何机器上显示一致，也不会有缺字。

## 每天换一句，也能手动换

打开时按当天日期算出一句，全天不变；即使刷新页面或重开 Harness，当天仍是同一句。

平常这条控制条是**隐藏**的，画面只留诗句。把鼠标移到诗句下方那片区域，`‹ › ⚙` 才会淡入；鼠标离开就自动隐去。（数字页码已按要求去掉，不再显示。）

| 按钮 | 作用 |
| --- | --- |
| ← / → | 上一句 / 下一句 |
| ⚙ | 打开设置面板 |
| 回到今日 | 手动切换后出现，点一下回到今天的句子 |

**每天随机换一句，不按固定顺序。** 当天日期作为种子把全部诗句打乱一次，于是每天随机、同一天刷新保持不变，而且一轮之内不会重复；一轮走完自动换新的一轮。手动切换保留到当天结束——第二天照常换成新的一句。

设置面板里可以调整：启用壁纸、显示出处、字体（行楷/草书/行草/行书）、字号（小/标准/大/特大）、纸色（跟随主题/宣纸/夜山）、墨色浓淡（淡/适/浓）、排布（自动/竖排/横排）、贴边（自动/左侧/右侧）。设置即时生效，存在本机浏览器里，不上传。把诗句拖动到任意位置（可以一直拖到窗口任意角落贴边），松手即记住；「恢复自动」可回到自动避让。设置面板会开在诗句旁边、不挡住诗。拖动只在确实移动后生效，单击按钮不会被误判成拖动。

## 诗句从哪来

全部来自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（MIT）：

- `水墨唐诗` —— 项目自己精选的 176 首唐诗，优先取用；
- `全唐诗` —— 李白、杜甫、王维、孟浩然、柳宗元等一级诗人，及一批常见诗人；
- `宋词` —— 苏轼、李清照、辛弃疾、柳永、欧阳修、姜夔等。

筛选时只保留：五言或七言的成对句、简体、无生僻缺字、不含应制/郊庙/贺寿一类非写景的句子，且至少命中两个意象标签（月、山、水、雨、雪、风、鸟、花、幽、夕、春、秋、行旅）。成句只取「同一段落内、上下两句」——一段就是一联（出句 + 对句），跨段落拼接会让读者看到错的诗，所以在建库阶段就掐掉了。另外，凡是含「四款字体里任何一个画不出的字」的句子也会被剔除（这类句子共 55 条，例如含「曛」「疎」「翃」的），因为缺字形会显示成方块或串字。最终收 371 句，同一作者最多 6 句，避免一个人刷屏。

上游数据本身的个别异体字/错字也做了校正（例如「一权寒梅」→「一树寒梅」、「平明送客楚江孤」→「楚山孤」、「韩竑」→「韩翃」、「鞭蓉山」→「芙蓉山」）。

## 注意

- 行楷用的是系统字体（macOS 自带 Xingkai SC）。Windows / Linux 上会先找「华文行楷」等同类字体，都没有才退回楷体；此时设置面板会提示「本机没有安装毛笔字体」。草书 / 行草 / 行书三款随插件附带，跨平台一致。
- 背景画在页面画布上，会话、卡片、输入框保持原有不透明度；只有大块空白处透出山水。若你另外装了会改页面配色的皮肤插件（例如海洋皮肤），两者会争抢同一层背景，建议只开一个。
- 诗句、字形、画面都在本机生成，不发网络请求。朱印是随插件附带的两张印面图（方印 / 圆印各一张），由 Host 半端从本地 `/ink-poem-wallpaper/` 路径提供，同样不联网。
